# Images

- `presenters/` – presenter photos. Set `photo: "file.jpg"` in `assets/js/content.js`.
- `team/` – team photos, same way.
- `brand/` – logos (only with permission to use them).

Square photos, at least 240x240 px, under ~200 KB each. Only add images you have permission to publish.
Without a photo the page shows initials.

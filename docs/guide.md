## Editing the site

- Edit all text in `assets/js/content.js`. Values starting with `[TBC` are placeholders.
- Add presenter photos to `assets/images/presenters/` and set `photo` in `content.js`.
- Preview by opening `index.html` in a browser.

## Deployment

The site deploys to GitHub Pages through `.github/workflows/static.yml` on every push to `main`. Only `index.html` and `assets/` are published. See `docs/06-deployment-guide.md`.
